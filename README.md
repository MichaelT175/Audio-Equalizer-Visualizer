# Audio Equalizer + Visualizer

Welcome to the Audio Equalizer + Visualizer project! This Java based application allows users to play audio files with customizable equalizer settings while viewing real-time visualizations of the audio spectrum.


## Features

### 🎵 Audio Equalizer

- Adjust Bass, Mid, and Treble levels using sliders.

- Gain control ranges from -20 dB to +20 dB for audio tuning.

### 📊 Audio Visualizer

- Spectrum Visualizer: Displays the audio frequency spectrum in real-time.

- Bar Visualizer: Visualizes the frequencies of the playing audio track.

### 🎶 Playlist Management

- Add your favorite audio files to the dropdown menu for quick selection.

- Easily switch between audio tracks.

### 💾 Preset Management

- Save customized equalizer settings as presets for individual tracks.

- Load previously saved presets, even after re-opening

### 🛠️ Additional Controls

- Playback controls: Play, pause, stop, and resume audio playback with dedicated buttons.

- Help Button: View the README file directly in the GUI for guidance.

## Installation

### Prerequisites

- Java Development Kit (JDK) version 8 or higher

- A Java IDE or build tool such as IntelliJ IDEA, Eclipse, or Maven

### Steps

- Clone this repository to your local machine:

- git clone https://github.com/MichaelT175/Audio-Equalizer.git

- Open the project in your preferred Java IDE.

- Ensure all dependencies are properly set up (e.g., required libraries for audio processing and GUI components).

- Run the EQGUI class to start the application.

### Usage

1. Launch the application by running the EQGUI class.
   
2. Add your desired audio files using the Add Song button.

3. Use the sliders on the left to adjust Bass, Mid, and Treble levels.

4. Save and load presets to fine-tune your favorite tracks.

5. Enjoy real-time visualizations while playing music!
